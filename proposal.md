# Предложение: мини-трекер учебных задач на неделю

## Цель

Создать автономный мини-трекер учебных задач на неделю: добавление,
удаление, отметка выполнения, фильтрация списка и расчёт прогресса по часам.

## Границы

Включено:
- Данные задачи: id, title, hours, done.
- Стартовые задачи: «Чтение» — 2 ч, готово; «Практика» — 4 ч,
  активно; «Повторение» — 2 ч, активно.
- Проверка названия и часов с ошибками рядом с полями.
- Фильтры «все / активные / готовые».
- Общие часы, выполненные часы и процент выполнения.
- Читаемый интерфейс на ширине 390 px без горизонтального скролла.
- Подписанные поля и кнопки.

Необязательное улучшение:
- Сохранение задач в localStorage с продолжением работы в памяти
  и понятным сообщением при недоступности хранилища.

## Варианты поставки

- A: один tracker-v2.html со встроенными CSS и JavaScript.
- B: index.html, styles.css, app.mjs, domain.mjs,
  tests/acceptance.test.mjs.

Оба варианта автономны: без CDN, внешних библиотек и API-ключей.
